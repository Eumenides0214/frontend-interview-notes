# 数据类型和typeof的陷阱

## 看点：

- typeof  null为什么返回“object”？
- 如何准确判断一个值是数组？
- 掌握JavaScript类型检查的终极武器。

## 两大类型：

- 原始类型（string/number/boolean/null/undefined/symbol/bigint）
- 对象类型（object 包含Array、Function等）

### 1.认识typeof操作符

- 是一个一元操作符
- 返回操作数类型的**字符串**表示

### 2.怎么用

- 原始类型

```
typeof 'hello';		//"string"
// fragment
typeof 123;		//"number"
// fragment
typeof true;	//"boolean"
// fragment
typeof Symbol('id');	//"symbol"
// fragment
typeof 123n;		//"bigint"
// fragment
typeof undefined;	//"undefined"
```

- 对象函数

```
typeof { a:1 };		//"object"
// fragment
typeof [1, 2, 3];	//"object"	<- 注意！
// fragment
typeof new Date();	//"object"
// fragment
typeof function() {};	//"function"(特殊)
```

### 3.typeof的两大核心陷阱

**陷阱1：typeof null**

```
console.log(typeof null); //"object"
```

**为什么？**

- 历史遗留bug
- JS早期实现中，null的底层表示是NULL指针（0x00）
- 对象的类型标签恰好也是0
- typeof错误将其识别为对象

**陷阱2：无法区分具体对象类型**

```
console.log(typeof []);	//"object"
console.log(typeof {}); //"object"
```

- typeof无法分辨Array和Object

### 4.解决方案与最佳实践

#### 如何判断null？

- 最佳实践：使用严格相等运算符 ===

- 代码示例：判断null

```
const myVar = null;

if (myVar === null) {		//[3]
	console.log('It is null!');
}
```

#### 如何判断数组Array？

- 最佳实践：使用Array.isArray()
- 代码示例：判断Array

```;
const arr = [];

console.log(Array.isArray(arr)); //true
console.log(typeof arr);         //"object"
```

#### 类型判断的“终极武器”

- Object.prottotype.toString.call()
- 代码示例：toString.call()

```
Object.prototype.toString.call(null);	//"[object Null]"
// fragment
Object.prototype.toString.call([]);		//"[object Array]"
// fragment
Object.prototype.toString.call({});		//"[object Object]"
// fragment
Object.prototype.toString.call('');		//"[object String]"
// fragment
Object.prototype.toString.call(123);	//"[object Number]"
```
